# Fraunces

`Fraunces-Bold.ttf` and `Fraunces-Black.ttf` are static instances of the
Fraunces variable typeface.

Copyright 2020 The Fraunces Project Authors (https://github.com/undercasetype/Fraunces)

This Font Software is licensed under the SIL Open Font License, Version 1.1.
The license is available with a FAQ at: https://openfontlicense.org

Fraunces is used for headlines and stat numerals only. If the font fails to
register at launch, the app falls back to the system serif design (see
`Design/Theme.swift`).
